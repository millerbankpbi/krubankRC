# KrubankRC — จอยบังคับหุ่น MATRIX Mini R4 แบบเรียลไทม์

**เปิดจอย (Bluetooth):** https://millerbankpbi.github.io/krubankrc/

บังคับหุ่นผ่าน Bluetooth จากลิงก์ด้านบน หรือผ่าน WiFi โดยเปิด `http://IP` ที่ขึ้นบนจอหุ่น (หุ่นส่งหน้าจอยให้เอง)

## ในชุดมีอะไร
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `arduino/KrubankRC/` | โปรเจกต์ Arduino เปิด `KrubankRC.ino` แล้วอัปโหลดลงหุ่น (กด Code → Download ZIP) |
| `arduino/KrubankRC/Buttons.ino` | แท็บที่ครูแก้บ่อยที่สุด: ปุ่มบนจอยสั่งหุ่นทำอะไร (คีบ วาง แขนขึ้นลง) |
| `index.html` | หน้าเว็บจอย (ลิงก์ GitHub Pages ด้านบน) |
| `make_rc_page.html` | ใช้ตอนแก้หน้าเว็บแล้ว อยากให้หุ่นส่งหน้าเว็บใหม่ผ่าน WiFi |

หุ่นเก็บหน้าเว็บไว้ในตัวแล้ว (`rc_page.h`) ถ้าใช้ WiFi ไม่ต้องอัปโหลดหน้าเว็บไปที่ไหนเลย

## ติดตั้งครั้งแรก
1. Arduino IDE เลือกบอร์ด **Arduino UNO R4 WiFi**
2. ต้องมีไลบรารี **MatrixMiniR4** และ **ArduinoBLE** (ครูมีอยู่แล้ว)
3. เปิด `KrubankRC.ino` แก้ 2 บรรทัดนี้ให้ตรงกับ hotspot มือถือ
   ```cpp
   const char* WIFI_SSID = "KRUBANK";   // ชื่อ hotspot
   const char* WIFI_PASS = "12345678";  // รหัส hotspot
   ```
4. อัปโหลด ถ้าจอขึ้น `WiFi module not found` หรือ `Bluetooth start failed` ให้อัปเดตเฟิร์มแวร์ไร้สายของบอร์ด: Tools → Firmware Updater

## ใช้ผ่าน WiFi (hotspot มือถือ) — แนะนำ
1. เปิด hotspot มือถือ **ต้องเป็นย่าน 2.4 GHz** (บอร์ดไม่รองรับ 5 GHz)
   - iPhone: เปิด “เพิ่มความเข้ากันได้สูงสุด / Maximize Compatibility”
   - Android: ตั้งย่านความถี่ hotspot เป็น 2.4 GHz
2. เปิดหุ่น กด **UP** ตอนจอขึ้นเมนู (หรือรอ 2.5 วิ ใช้ WiFi เป็นค่าเริ่มต้น)
3. จอหุ่นขึ้น IP เช่น `WiFi 172.20.10.3`
4. มือถือเปิด Chrome พิมพ์ `http://172.20.10.3` หน้าจอยขึ้นและต่อเองทันที (จุดเขียว)

ถ้าหุ่นหา hotspot ไม่เจอ หุ่นจะปล่อย WiFi ชื่อ `KRUBANKR4` รหัส `12345678` เอง ให้มือถือต่อ WiFi นั้นแล้วเปิด `http://192.168.4.1`
ถ้าอยากใช้แบบนี้ตลอด ตั้ง `WIFI_SSID = ""`

## ใช้ผ่าน Bluetooth
1. เปิดหุ่น กด **DOWN** จอขึ้น `BLE KRUBANKR4`
2. เปิด https://millerbankpbi.github.io/krubankrc/
   - Android ใช้ Chrome · iPhone ใช้แอป **Bluefy**
3. แตะแถบสถานะ → Bluetooth → เชื่อมต่อ → เลือก `KRUBANKR4`

## หน้าจอย
- **แถบบน**: ⚙ ตั้งค่า · ระดับความเร็ว ช้า/กลาง/เร็ว · แถบกำลังล้อซ้าย-ขวา `ซ้าย, ขวา | DRV | TRN | ความหน่วง ms | แบต` · สถานะการเชื่อมต่อ · ✎ จัดวางปุ่ม · ⛶ เต็มจอ
- แตะแถบตัวเลขเพื่อเลื่อน DRV (วิ่ง) และ TRN (เลี้ยว) ได้ทันทีระหว่างขับ
- **รูปแบบการบังคับ** (⚙ → การขับ): คันโยก · คันโยกคู่ (ซ้ายวิ่ง ขวาเลี้ยว) · ปุ่มทิศ (กดเฉียงได้) · แทงก์
- ปุ่ม **หยุด** สีแดง = หยุดล้อและแขนทันที
- ✎ จัดวาง: ลากย้าย · − + ย่อขยาย · ▦ จัดตามตาราง · ↶ ↷ ย้อน/ทำซ้ำ · แก้ปุ่ม · ＋ปุ่ม · ซ่อน · ⟲ คืนตำแหน่ง
- คอมพิวเตอร์: ลูกศร/WASD ขับ · Shift เร่ง · Space หยุด · เลข 1–8 = ปุ่ม 1–8 · ต่อจอยเกม USB/Bluetooth ได้

## ตั้งปุ่มเอง
⚙ → ปุ่ม → แก้ แต่ละปุ่มเลือกได้ว่า
- **ส่งข้อความไปหุ่น**: ตอนกด / ตอนปล่อย / กดค้างส่งซ้ำทุกกี่ ms
- **กดสลับ เปิด/ปิด** · **กดค้างเพื่อเร่งสุด** · **สลับระดับความเร็ว** · **หยุดฉุกเฉิน**

ข้อความที่ใช้ได้ทันทีโดยไม่ต้องแก้โค้ด

| ข้อความ | หุ่นทำ |
|---|---|
| `S2=90` | servo RC2 ไป 90° (ค่อย ๆ ไปใน 0.3 วิ) |
| `S2=90@800` | ไป 90° ภายใน 800 ms |
| `S2+5` `S2-5` | เพิ่ม/ลด 5° (ตั้งกดค้างส่งซ้ำ แขนจะขยับต่อเนื่อง) |
| `BEEP` `BEEP=2000,300` | เสียงบี๊บ |
| `LED=0,80,0` | ไฟบนบอร์ด |
| `STOP` | หยุดทุกอย่าง |
| `KEEP` `DROP` `OPEN` `CLOSE` `ARMUP` `ARMDOWN` | ท่าแขนคีบ เขียนไว้ใน `Buttons.ino` |

เพิ่มคำสั่งชื่อใหม่ได้ใน `onButton()` แท็บ `Buttons` มุม servo แขนคีบใช้ค่าเดียวกับ `Gripper.ino`
ท่าคีบ/วางทำงานแบบไม่หยุดโปรแกรม ระหว่างแขนเคลื่อน หุ่นยังวิ่งตามจอยได้

## ปรับความรู้สึกการขับ (`KrubankRC.ino`)
| ค่า | ความหมาย |
|---|---|
| `MAX_POWER` | กำลังสูงสุดที่หุ่นยอมวิ่ง |
| `ACCEL_PER_S` | ความไวในการออกตัว (800 = 0→100 ใน 0.13 วิ) ใส่ 0 = กระชากทันที |
| `DECEL_PER_S` | ความไวตอนผ่อน/เบรก |
| `BRAKE_ON_STOP` | ปล่อยจอยแล้วเบรก (`false` = ไหลต่อ) |
| `DRIVE_TIMEOUT_MS` | ไม่ได้รับคำสั่งเกินนี้ หุ่นหยุดเอง (กันหุ่นวิ่งหนีตอนสัญญาณหลุด) |
| `LEFT_REVERSE` `RIGHT_REVERSE` | ทิศมอเตอร์ เหมือน `DriveDC.begin(1, 2, false, true)` |

หุ่นวิ่งตรงแล้วเฉ: ⚙ → การขับ → แก้หุ่นวิ่งเฉ

## แก้หน้าเว็บแล้วอยากให้หุ่นส่งหน้าใหม่
แก้ `index.html` → เปิด https://millerbankpbi.github.io/krubankrc/make_rc_page.html → เลือกไฟล์ `index.html` → ได้ `rc_page.h` → วางทับใน `arduino/KrubankRC` → อัปโหลดลงหุ่นใหม่

## แก้ปัญหา
| อาการ | ทางแก้ |
|---|---|
| จอขึ้น `hotspot not found` | เช็กชื่อ/รหัส และ hotspot ต้องเป็น 2.4 GHz |
| เปิด IP แล้วหน้าเว็บไม่ขึ้น | พิมพ์ `http://` นำหน้า มือถือต้องต่อ hotspot/WiFi เดียวกับหุ่น |
| ตัวเลข ms ขึ้นสูงค้างเกิน 80 ms | ลองโหมดหุ่นปล่อย WiFi เอง (`WIFI_SSID = ""`) หรือ Bluetooth |
| หน้าเว็บบอกต่อ WiFi ไม่ได้เพราะ https | WiFi ต้องเปิดหน้าจากหุ่นตรง `http://IP` ไม่ใช่ลิงก์ https |
| Bluetooth หาไม่เจอ | หุ่นต้องเลือก DOWN ตอนเปิดเครื่อง · iPhone ใช้ Bluefy · Android เปิดตำแหน่ง |
| กดปุ่มแล้วขึ้น “หุ่นไม่รู้จักคำสั่ง” | ข้อความในปุ่มไม่ตรงกับ `onButton()` หรือคำสั่งสำเร็จรูป |
| ปุ่มเยอะเกินไม่ได้ใช้ | ✎ → เลือกปุ่ม → ซ่อน |
